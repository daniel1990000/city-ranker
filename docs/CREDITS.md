# Credits and licences

Everything in Cage Kings is original or used under a licence that allows a paid, closed-source game.
Nothing comes from EA SPORTS UFC, the UFC, or any real fighter or brand.

## Fighters
- **MakeHuman system assets** (base meshes, game-weight "muscle" proxy bodies, skins, eyes, eyebrows, eyelashes,
  teeth, hair styles): CC0 1.0, released by Data Collection AB, Joel Palmius and Jonas Hauquier in 2020.
  https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- **MPFB 2** (MakeHuman plugin for Blender) is used as a build tool only; its assets are CC0 and models exported
  with it may be used in closed-source commercial games
  (https://static.makehumancommunity.org/mpfb/faq/use_in_closed_source.html). Its GPL code is not shipped.
- Shorts, gloves, sports tops, tattoos, stubble and damage are generated by our own code.

## Fonts
- Oswald and Inter: SIL Open Font License 1.1 (google/fonts). Licence texts ship next to the files (src/ui/fonts).
- The launcher icon and splash use Inter Display Bold (SIL OFL 1.1) to draw "CK" / "CAGE KINGS".

## Everything else
- Sound: synthesised in code, no sample files: a small start-up bank (src/audio/sound.ts) and the full arena bank
  (impacts, crowd voices, bell, UI stings, menu music: src/audio/sfx.ts, crowd.ts, music.ts, built in a worker).
- Arena, crowd, mat logo, crown mark, invented sponsor names, icons: drawn by our own code.
- Animation: keyframed in code (src/render/fighter/clips.ts) with our own IK solver.
