# Cage Kings

An original 3D MMA fighting game with realistic fighters, for Android phones (landscape).

- Fight with touch: tap to jab, swipe for power punches, kick button for kicks, hold to block, flick to slip, swipe
  down to shoot a takedown, then win the ground scramble or the submission tap battle.
- Climb the career ladder in six weight classes (Amateur to Champion), collect and train 48 original fighters, open
  packs, and play the monthly Season Pass.

Docs: `docs/MASTER-PLAN.md` (the plan), `docs/ARCHITECTURE.md` (how the parts fit), `docs/FIGHT-DESIGN.md`,
`docs/ECONOMY.md`, `docs/RELEASE.md`, `docs/REMOTE-TUNING.md`, `docs/CREDITS.md`. Developer notes: `CLAUDE.md`.

```sh
npm install
npm run dev     # play in the browser (keyboard: J K U I O L punches, N M , kicks, S block, Q/E slip, Space takedown)
npm test
```
