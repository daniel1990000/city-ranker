### The 21 aggression inputs **[DATA]**
`health_head, health_body, health_leftleg, health_rightleg, delta_health, in_hit_reaction, idle, stamina,
opp_health_head, opp_health_body, opp_health_leftleg, opp_health_rightleg, opp_delta_health, opp_in_hit_reaction,
opp_idle, opp_stamina, opp_strike_activity, planner, round_num, round_time, score_differential`.
(Own state, opponent state, tempo, and match context. `planner` is the planner's own contribution.)

## 2. Recommended architecture **[REC]**

```
Perception  → FighterSituation (range, angles, cage flags, stamina/health %, current event, round clock, score diff)
Strategy    → aggression A∈[Amin,Amax] from the 21 factors   +  tendency desirabilities  (+ skills)
Tactics     → choose a goal type by weighted draw; choose a concrete action via per-goal selectors; check legality
Execution   → emit the *same intents* a human controller produces (strike slot/side/target, guard, move vector, grapple)
Timing      → difficulty curve: reaction delay, accuracy of reads, combo length, mistake rate
```

### 2.1 Aggression
```
A = clamp( A0[t] + Σ_i w_i[t] · curve_i(f_i) , Amin[t], Amax[t] )         t = tendency
f (all normalised to [0,1] or [−1,1]):
  own head/body/leg health%, stamina%, delta_health (damage taken in last 8 s), in_hit_reaction, idle time
  opponent versions of all of the above, opp_strike_activity (strikes/s ÷ 3)
  round_time (elapsed/limit), round_num (n/total), score_differential (−1 losing … +1 winning)
  planner (bias from last plan outcome)
```
Starting weights (sign convention: + = increases aggression): opp_head_health: −0.35 (hurt opponent ⇒ press), opp_stamina: −0.20,
own_stamina: +0.25, own_head_health: +0.20, in_hit_reaction: −0.30, score_differential: −0.25 (losing ⇒ push),
round_time: +0.10 (late-round urgency), idle: +0.15. Tendency overrides: `brawler A0=0.75, Amin 0.45`; `chess_master A0=0.40,
Amax 0.75`; `attrition_specialist` scales `opp_stamina` ×2; `adaptive_finisher` boosts `opp_head_health` ×1.8.

### 2.2 Goal selection (planner-lite)
Goal types (observed): `strike, special_strike, loco, transition, takedown, clinch, submission` (+ defensive reactions).
```
score_g = base[t][g] · fit_g(situation) · (1 + interest_g) · (0.9 + 0.2·rng) · aggressionGain(g, A)
choose  = softmax(score / τ)   with τ = 0.35 (champion) … 0.8 (beginner)    # mistakes grow with τ
```
* `fit_strike`: in-range window, stance angle, opponent in recovery ⇒ ×1.6; `fit_takedown`: range + opp strike activity low + cage ⇒ ×1.3.
* `interest_takedown = clamp((takedown − takedowndefense_opp)/50, −1, 1)`; similarly clinch (`clinchcontrol` spread) and
  submissions (own/opp stamina, stage — the three observed factors).
* Tendency base weights (examples): `striking_purist` strike .55 / loco .30 / clinch .05 / takedown .05 / sub .05;
  `bjj_fighter` takedown .30 / clinch .20 / strike .25 / sub .15 / loco .10; `thai_clincher` clinch .35 / strike .35;
  `dirty_boxer` clinch strikes & uppercuts ×1.4; `damage_specialist` special strikes ×1.5; `dominance_specialist` takedown/ground ×1.4.
* After picking a goal, a **selector** resolves details: strike → `(side, slot, target)` using the fighter's
  loadout, favouring combos that chain via branch windows; loco → angle to circle/cut off; transition → ground graph move.

### 2.3 Defence and reaction (difficulty)
`reactionTicks = curve(difficulty)`: beginner 26±8, pro 16±5, champion 8±3. Defensive decision made when an incoming
strike enters `startup`; the AI succeeds in guarding/parrying/slipping with `p_def = base[difficulty] + 0.002·blocking`
(beginner 0.30, pro 0.55, champion 0.78); on read failure it takes the hit. `hands_down` archetypes lower `p_def`.

### 2.4 Commitment and cadence
New goal every 12–24 ticks when idle; committed until the action finishes; combos (2–4 strikes) planned at start;
aggression A sets inter-action gap: `gap = lerp(34, 6, A)` ticks.

### 2.5 Submission AI
Choose to attempt if `p = base · fit(positionHasSub) · f(own stamina, opp stamina, stage)`; during a session choose gate/prompt
actions by `completion proximity` and `stamina/time cost`; abort if own stamina < 15 %.

### 2.6 Optional: learning/playback ("style imitation") **[REC, inspired by RealAI]**
Log `(situation bucket → action, outcome)` rows from human fights; build per-fighter tables; the AI samples from them with
probability `imitation∈[0,1]` (difficulty-linked), else uses the archetype model. Storage format and bucketing in `18`.

### 2.7 Scripted AI for tutorials **[DATA]**
`ai_style="FTUE"` fights (`ftue_{blue,red}_corner_fight1..4.xml`) and `AiScriptedActionSubmission` show tutorials are
**scripted opponents**: expose a `ScriptedBrain` that replays a sequence of intents with trigger conditions.

## 3. Acceptance tests (`reference/test/ai.test.js`)
1. Aggression is monotone in each factor in the documented direction; clamped to `[Amin,Amax]`.
2. Over 5 000 draws, goal frequencies converge to the tendency base weights (±3 %).
3. Champion reacts faster than beginner (mean reaction ticks) and blocks more often.
4. AI never emits an illegal intent (out of range strike, stamina < cost, wrong mode).
5. Same seed ⇒ identical decisions.
6. `ScriptedBrain` executes the scripted sequence exactly once.
